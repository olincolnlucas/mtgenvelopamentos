# MTG Envelopamentos

Site institucional completo da MTG Envelopamentos, com a versão responsiva aprovada para celular, tablet e desktop.

## Arquivos

- `index.html`: estrutura, seções e informações do site.
- `styles.css`: identidade visual, layouts responsivos e correção do deslocamento horizontal no celular.
- `content.js`: projetos, galerias, comparação antes/depois e contato.
- `script.js`: menu, galerias, vídeos e interações.
- `assets/`: todas as imagens, logos, mockup, prévia de compartilhamento e vídeos usados pelo site.
- `vercel.json`: configuração de hospedagem estática na Vercel.

## Publicação

Importar este repositório na Vercel com o nome `mtgenvelopamentos`, usando a branch `main` e a pasta raiz. O site não precisa de instalação nem compilação. As configurações estão no `vercel.json`.

Após a conexão, novos commits na branch de produção são publicados pela integração GitHub/Vercel.

## Edição e prévia local

Editar os arquivos diretamente e servir esta pasta com um servidor HTTP local. Exemplo: `python3 -m http.server 8080`.
